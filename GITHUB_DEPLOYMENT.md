## Step 7: Create GitHub Repository

### Option A: Via GitHub Website

1. Go to [GitHub](https://github.com)
2. Click the **"+"** icon in the top right
3. Select **"New repository"**
4. Fill in repository details:
   - **Repository name**: `sales-data-analytics-dashboard`
   - **Description**: `Retail sales data analytics project with Python and Power BI`
   - **Visibility**: Public (or Private)
   - **DO NOT** initialize with README, .gitignore, or license (we already have these)
5. Click **"Create repository"**

### Option B: Via GitHub CLI (gh)

```bash
# Install GitHub CLI first
# Windows: winget install GitHub.cli
# macOS: brew install gh
# Linux: See https://cli.github.com/manual/installation

# Login to GitHub
gh auth login

# Create repository
gh repo create sales-data-analytics-dashboard --public --source=. --remote=origin --push
```

## Step 9: Push to GitHub

```bash
# Push to GitHub
git push -u origin main

# Enter your GitHub credentials when prompted
# (Use a Personal Access Token instead of password)
```

### Creating a Personal Access Token (PAT)

If you need a token:

1. Go to GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Click "Generate new token" → "Generate new token (classic)"
3. Give it a name: `Sales Analytics Project`
4. Select scopes:
   - ✅ `repo` (all sub-options)
   - ✅ `workflow`
5. Click "Generate token"
6. **Copy the token** (you won't see it again!)
7. Use this token as your password when pushing

## Troubleshooting

### Issue: "Permission denied (publickey)"

**Solution**: Set up SSH key or use HTTPS with Personal Access Token

```bash
# Switch to HTTPS
git remote set-url origin https://github.com/yourusername/sales-data-analytics-dashboard.git
```

### Issue: "Updates were rejected"

**Solution**: Pull first, then push

```bash
git pull origin main --rebase
git push origin main
```

### Issue: Large files rejected

**Solution**: Use Git LFS or don't commit large files

```bash
# Install Git LFS
git lfs install

# Track large files
git lfs track "*.pbix"
git lfs track "*.csv"

# Add .gitattributes
git add .gitattributes
git commit -m "chore: add Git LFS tracking"
```

### Issue: Forgot to add .gitignore before commit

**Solution**: 

```bash
# Remove files from Git (but keep locally)
git rm --cached data/cleaned_sales_data.csv
git rm --cached images/quick_analysis.png

# Commit the removal
git commit -m "chore: remove generated files from tracking"

# Push
git push
```
