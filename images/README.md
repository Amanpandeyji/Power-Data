# Dashboard Images

## Purpose
This folder contains screenshots and images related to the Power BI dashboard.

## Required Images

### 1. dashboard_preview.png
- **Description**: Main screenshot of the Power BI dashboard
- **Recommended Size**: 1920x1080 or 1280x720
- **Format**: PNG (for transparency and quality)
- **How to capture**: 
  - Open your Power BI dashboard
  - Press `Print Screen` or use Snipping Tool (Windows)
  - Save as `dashboard_preview.png` in this folder

### 2. Additional Screenshots (Optional)

You may want to add:
- `kpi_cards.png` - Close-up of KPI indicators
- `revenue_trend.png` - Monthly revenue chart
- `regional_map.png` - Map visualization
- `category_analysis.png` - Product category breakdown
- `segment_performance.png` - Customer segment analysis

## Tips for Screenshot Quality

✅ **Use high resolution** - Capture at full screen  
✅ **Clean view** - Remove unnecessary UI elements  
✅ **Good contrast** - Ensure text is readable  
✅ **Highlight key insights** - Use annotations if needed  
✅ **Consistent style** - Use same theme/colors  

## Creating Professional Screenshots

### Option 1: Power BI Export
1. Open your dashboard in Power BI Desktop
2. Go to **File** → **Export** → **Export to PowerPoint**
3. Extract images from PowerPoint
4. Save as PNG files

### Option 2: Snipping Tool (Windows)
1. Open Snipping Tool or Snip & Sketch
2. Select **New** or press `Windows + Shift + S`
3. Capture the desired area
4. Save with appropriate filename

### Option 3: Screenshot with Annotations
1. Take screenshot using method above
2. Open in image editor (Paint, PowerPoint, etc.)
3. Add arrows, callouts, or highlights
4. Export as PNG

## Image Naming Convention

Use descriptive filenames:
- `dashboard_preview.png` - Main dashboard view
- `revenue_analysis.png` - Revenue-focused view
- `regional_breakdown.png` - Regional analysis
- `mobile_view.png` - Mobile layout
